suraj joshi.

i’m a guy on a mission to become a full-stack roboticist. it’s a long journey, and i’m currently navigating it with yondu ai, where we’re tackling the challenge of deploying robots in the real world, starting with warehouses in the logistics industry.

i have been exploring robotics for almost two years now. my work spans the control stack (controllers, motion planning, and inverse kinematics), teleoperation stack (exoskeleton-based teleoperation, vr teleoperation, and remote teleoperation systems), and robot learning stack (imitation learning and reinforcement learning).

i also have hands-on experience with simulators and real robots, including single-arm and bimanual systems and whole-body robots (wheeled robots and humanoids). i have worked with multiple end effectors, including parallel-jaw grippers and dexterous hands.

before entering robotics, i worked in software development, mostly doing backend engineering, building data pipelines, and working with distributed systems. i am a big fan of startups, and i feel lucky to have been part of the founding teams of four amazing startups so far.

i am currently interested in doing research on robot learning, with the goal of deploying autonomous robots in the real world that match human-level accuracy, reliability, and throughput.

RoboEngine: Plug-and-Play Robot Data Augmentation with Semantic Robot Segmentation and Background Generation

Chengbo Yuan*, Suraj Joshi*, Shaoting Zhu*, Hang Su, Hang Zhao, Yang Gao.

project page arXiv code dataset

IEEE/RSJ International Conference on Intelligent Robots and Systems (IROS), 2025 · Oral

* Equal contribution

A plug-and-play toolkit that combines robot segmentation and background generation to create physics- and task-aware training scenes. It helps imitation-learning policies generalize to new environments using demonstrations collected in a single scene.

Can mentalizing shapes lead to empathy in humans?

V. Srivastava, M. Goel, Suraj Joshi, S. Shrestha.

abstract book code

7th Annual Conference of the Association for Cognitive Science in India (ACCS), 2021 · pp. 120–121

A study of whether attributing mental states to moving shapes can evoke empathy. The analysis compares brain activation and functional connectivity across regions associated with mentalizing and empathy.

Selected projects.

01
robot learning · world modelsresearch project

improving imitation learning policies with world-model supervision

can a policy learn from the predicted consequences of its actions, alongside demonstrations? this project explores an additional training signal from a frozen world model, comparing the futures predicted for the policy's actions with those predicted for demonstrated actions.

read the technical report ↗

02
dexterous manipulation · reinforcement learningresearch project

bidexoid: bimanual dexterous manipulation

learning coordinated upper-body motion for bimanual dexterous manipulation from a single human reference. kinematic retargeting prepares the arm and finger motion, and reinforcement learning jointly adapts both to reproduce the demonstrated object motion and contacts.

read the technical report ↗

03
humanoid motion · scene perceptionresearch project

scene-aware humanoid motion generation

conditioning a motion diffusion model on lidar geometry to generate a route and whole-body motion for the unitree g1. this project extends kimodo with scene encoders and terrain-relative motion, then chains local windows into longer kinematic motion sequences.

read the technical report ↗

04
robot teleoperation · collision avoidanceresearch project

real-time external collision avoidance for robot teleoperation

this project brings external obstacles into a vr teleoperation inverse-kinematics pipeline. depth-camera point clouds become constraints inside the ik solver, limiting motion toward nearby obstacles while the arms track the operator’s targets. the arm-control loop runs at approximately 110 hz.
